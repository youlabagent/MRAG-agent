# OC2 example report

`mrag_report.html` is a standalone HTML report (3.6 MB). GitHub's file viewer cannot display files this large
(*"Sorry about that, but we can't show files that are this big right now."*), so use one of these:

- **Open online:** <https://youlabagent.github.io/MRAG-agent/examples/OC2/mrag_report.html>
- **Download:** open [`mrag_report.html`](mrag_report.html) and click the download button at the top right of
  the file page, or right-click the [raw file link](https://github.com/youlabagent/MRAG-agent/raw/main/examples/OC2/mrag_report.html)
  and choose *Save Link As...*.

See the [examples README](../README.md) for what the report contains and how it was produced.
