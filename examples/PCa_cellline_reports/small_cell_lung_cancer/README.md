# PCa cell-line report: small cell lung cancer domain

`mrag_report.html` is the OC2 report (LNCaP, `ONECUT2-OE` vs `MYC-DDK`) run with
`literature_domains = ["sclc"]` (Small cell lung cancer). It is a standalone HTML report (3.6 MB). GitHub's file viewer
cannot display files this large (*"Sorry about that, but we can't show files that are this big right now."*),
so use one of these:

- **Open online:** <https://youlabagent.github.io/MRAG-agent/examples/PCa_cellline_reports/small_cell_lung_cancer/mrag_report.html>
- **Download:** open [`mrag_report.html`](mrag_report.html) and click the download button at the top right of
  the file page, or right-click the [raw file link](https://github.com/youlabagent/MRAG-agent/raw/main/examples/PCa_cellline_reports/small_cell_lung_cancer/mrag_report.html)
  and choose *Save Link As...*.

See [PCa cell-line reports](../README.md) for how the three domain runs differ, and the
[examples README](../../README.md) for what a report contains and how it was produced.
